s1b Soil Lookup — GEOID → k, α, T_g
Input
run a trace
How it works (pre-computed)
Côté-Konrad (2005): n = 1 − ρ_d / 2.65 k_s = 7.7^q × 2.0^(1−q) k_sat = k_s^(1−n) × 0.6^n k_dry = χ × 10^(−η×n) k_e = (κ·S_r)/(1+(κ−1)·S_r) k = (k_sat−k_dry)·k_e + k_dry α = k/(ρ_d·750)×86400 [m²/day] Data: USGS SSURGO + DS-801
Output

s2 Building Loads — Building Type × Climate → q_h, q_m, q_y
Input
run a trace
How it works (pre-computed)
EnergyPlus (developer pipeline): 1. DOE prototype IDF × climate zone 2. Add ZoneHVAC:IdealLoadsAirSystem 3. Run 8760h simulation 4. Extract Zone Sensible Heating/ Cooling Rate (hourly) 5. Aggregate to 3 pulses (s3_loads): ground[h] = q_cool[h] − q_heat[h] q_h = peak hour ground load q_m = peak month avg q_y = annual average
Output — Three-Pulse Ground Loads

s4 Borefield Sizing — Philippe et al. (2010)
Inputs consumed

Equations applied
Rb = R_grout + (R_conv+R_pipe)/2 R_6h = g(α,rbore,A_F6H)/k R_1m = g(α,rbore,A_F1M)/k R_10y= g(α,rbore,A_F10Y)/k Tm = T_in_HP + q_h/(ṁ·Cp) L₀ = (q_y·R_10y+q_m·R_1m +q_h·R_6h+q_h·Rb) /(Tm − T_g) Iterate: Tp → L until |ΔL|<1m
