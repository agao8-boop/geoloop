s1b Soil Lookup — GEOID → k, α, T_g
Input
run a trace
How it works (pre-computed)
Côté-Konrad (2005): n = 1 − ρ_d / 2.65 k_s = 7.7^q × 2.0^(1−q) k_sat = k_s^(1−n) × 0.6^n k_dry = χ × 10^(−η×n) k_e = (κ·S_r)/(1+(κ−1)·S_r) k = (k_sat−k_dry)·k_e + k_dry α = k/(ρ_d·750)×86400 [m²/day] Data: USGS SSURGO + DS-801
